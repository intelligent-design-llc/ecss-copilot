# Code of Conduct

We want ECSS Copilot to be a welcoming, professional community for engineers and developers of all backgrounds.

**Expected:** be respectful and constructive, assume good intent, focus on the technical issue, and accept feedback gracefully.

**Not acceptable:** harassment, insults or personal attacks; discriminatory language or imagery; publishing others' private information; sharing confidential, proprietary or export-controlled material; and any conduct that would be inappropriate in a professional setting.

**Enforcement:** maintainers may edit or remove contributions, and may temporarily or permanently ban participants who violate this code. Report concerns privately to the maintainers via GitHub (for example, through the repository's private security reporting channel or a direct message to a maintainer).

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
